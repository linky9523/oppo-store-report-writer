# OPPO 门店导购业务背景

本文件为写日报/周报提供业务上下文。导购在门店一线接待用户、销售 OPPO 集团产品，报告需使用正确的品牌术语、产品线与指标口径。

## 一、产品线认知

OPPO 门店同时承载多品牌产品，报告涉及机型须使用准确系列名与命名规范。

| 系列 | 定位 | 典型机型（示例） | 适用人群 |
|---|---|---|---|
| Find 系列 | 高端旗舰 / 折叠屏 | Find X9s Pro、Find N6（折叠）、Find 6 | 商务人士、影像/科技发烧友、追求旗舰体验用户 |
| Reno 系列 | 中高端影像潮流 | Reno16（白/黑等配色） | 年轻用户、大学阶段、注重拍照与设计 |
| 一加系列 | 性能旗舰 | 一加旗舰 | 性能用户、游戏玩家、参数敏感型用户 |
| A 系列 | 长续航高性价比 | A7 Promax（10000mAh）、A6K（7000mAh） | 预算有限用户、外卖/快递从业者、长辈群体、续航刚需用户 |
| IoT / 配件 | 智能穿戴与配件 | Watch X3、手表、耳机、贴膜、碎屏险等 | 全人群增值 |

注意事项：
- 机型命名区分大小写与版本，如 "X9s Pro"（非"x9s pro"）、"Reno16 白&黑"、"Find N6"（折叠，对标华为/vivo折叠、小米17）。
- 同一型号按内存配置区分价位（如 16+512），价格沟通需结合"店补后比线上更划算"等话术。
- 折叠屏为竞品焦点评级点，强调"无折痕、更轻薄、价格优势"。

## 二、关键业绩指标（KPI）

周报固定 10 项业绩指标，日报"个人今日数据"中常用同类口径，需一致使用。

| 指标 | 含义 | 报告中常见表述 |
|---|---|---|
| 手机销量（独销） | 本人独立完成销售的手机台数 | "手机独销3台" |
| IOT销量（独销） | 本人独立销售的 IoT/配件（手表耳机等）数量 | "IOT 1" |
| 付费膜销量 | 售出付费贴膜单数 | 高毛利增值项 |
| 当换回收数量 | 以旧换新回收旧机数量 | "当换1台" |
| 有效授权企微数量 | 成功添加并授权的企业微信客户数 | "新增企微3""有效企微9" |
| 大众点评数量 | 引导用户在大众点评留下的有效评价数 | 门店口碑指标 |
| 地图好评数量 | 在地图类平台留下的好评数 | 门店口碑指标 |
| 免费贴膜数量 | 免费贴膜服务单数 | 引流增值工具，每月免费 |
| 发布抖音数量 | 本人发布抖音内容条数 | 门店曝光 |
| 发布小红书数量 | 本人发布小红书内容条数 | 门店曝光/新品预热 |

衍生术语：
- "独销"：独立完成销售（区别于协销/分单）。
- "当换"：以旧换新；"三图指标"指某三项图表相关达标指标（门店常用简述）。
- "三图""导流""预热"为门店运营黑话，可直接沿用。

## 三、常见销售场景与话术要点

报告"典型案例""售机过程"常出现以下场景，写作时按此逻辑组织：

1. 跨品牌纠结用户（如小米17 vs X9s Pro、苹果换机）：首推本品牌旗舰，强调独家影像（双两亿、哈苏）、系统流畅（ColorOS）、换机适应度、店补后价格优于线上平台。
2. 预算敏感/性价比用户：先推高配长续航机型，嫌贵则下探 A 系列大电池机型（如 A7 Promax→A6K），强调续航与价格。
3. 老用户复购/换机：OPPO 全家桶用户（手机+手表），调研满意度与新需求（如方形表盘、阔折叠兴趣）。
4. 折叠屏意向用户：告知本品牌折叠推新节奏，强调无折痕/轻薄/价格，对标友商新品。
5. 免费贴膜到店用户：利用贴膜停留时间转化碎屏险、运营商套餐返现等增值。
6. 外籍/特殊用户：主动询问需求，按性价比+续航匹配机型。

## 四、运营与门店观察维度

"收获与思考""个人思考"常涉及以下维度，写作时可引导用户从这些角度提炼：

- 客流与进店率（工作日低位、友商虹吸、苹果发布会后看 N6 用户提升等）
- 用户消费决策特征（性格果断/纠结、消费心态而非仅消费能力）
- 营销人群定位 vs 走进具体的人（TA 辅助而非限制销售）
- 竞品动作观察（友商提前放真机、新品预热节奏差异）
- 门店陈列与物料（直播神器光圈物料不直观、价签误导、缺少实拍案例图）
- 增值服务价值（免费贴膜引流、付费贴膜高毛利、企微沉淀客户）
- 客户沉淀与线上引流（企微加微理由、小红书/抖音内容种草）

## 五、报告语言风格

- 第一人称叙述（"我首推""我立马告知"）。
- 售机过程用编号步骤（1）2）3））呈现节奏。
- 收获思考用编号要点（1、2、3、），每点含观察+洞察。
- 长文本段落用换行分隔，避免整块文字墙。
- 数据用阿拉伯数字，机型保留品牌规范写法。
