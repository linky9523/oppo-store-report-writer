# 周报字段结构与写作规范

周报为 Excel 版式（OPPO 绿标题 + 纵向布局），单周一份。以下为字段结构、10 项 KPI 定义、各 section 写作规范与 xlsx 布局规格。

## 一、整体结构

```
[标题行] 上海团队 {姓名} 第 {N} 周总结            ← A1，合并 A:J，OPPO绿底白字 14pt bold
[基本信息]
  派驻地：{派驻地}                                ← A2标签 + B2:J2值
  所在售点：{售点全称}                            ← A3 + B3:J3
  姓名：{姓名}                                    ← A4 + B4:J4

[一、本周概述（销售业绩、总结反思）]              ← A5 一级标题（合并A:J，bold）

  1. 销售业绩及指标达成                           ← A6 二级标题
    [10项指标表]                                  ← A7:J7 表头(浅灰底) + A8:J8 数值
    业绩达成情况分析                              ← A9标签 + B9:J9 长文本

  2. 收获与反思                                   ← A10 二级标题
    个人收获                                      ← A11 + B11:J11 长文本
    不足反思与提升计划                            ← A12 + B12:J12 长文本

  3. 个人思考                                      ← A13 二级标题
    门店提升机会与提升方案                        ← A14 + B14:J14 长文本

  4. 竞品分析与对标                                ← A15 二级标题
    竞品销量、赢输与对标                          ← A16 + B16:J16 长文本

[二、下周计划]                                    ← A17 一级标题
  [计划表]                                        ← A18:D18 表头 + A19:D21 三行数据
    序号 | 参考维度 | 目标/计划 | 关键行动计划
```

## 二、10 项业绩指标（周报固定）

按 A→J 列顺序，表头与口径固定，数值为本周累计：

| 列 | 表头（A7:J7） | 含义 | 取值 |
|---|---|---|---|
| A | 手机销量（独销） | 本人本周独立销售手机台数 | 整数 |
| B | IOT销量（独销） | 本人独立销售 IoT/配件数 | 整数 |
| C | 付费膜销量 | 售出付费贴膜单数 | 整数 |
| D | 当换回收数量 | 以旧换新回收旧机数 | 整数 |
| E | 有效授权企微数量 | 新增有效企业微信客户数 | 整数 |
| F | 大众点评数量 | 引导留下的有效评价数 | 整数 |
| G | 地图好评数量 | 地图平台好评数 | 整数 |
| H | 免费贴膜数量 | 免费贴膜服务单数 | 整数 |
| I | 发布抖音数量 | 本周发布抖音条数 | 整数 |
| J | 发布小红书数量 | 本周发布小红书条数 | 整数 |

注意：全部为静态数值，无公式。日报同周各日数据相加即得周累计。

## 三、各 section 写作规范

### 业绩达成情况分析（B9）
150-250 字长文本。结构：
- 开头概述本周累计完成的销量、IOT、企微、贴膜等核心数据（与10项指标呼应）。
- 说明成交机型覆盖的系列（Find/Reno/一加/A）。
- 总结一周门店实践的成长（接待→需求挖掘→讲解→成交→售后各环节的认识）。
- 收束到为后续提升成交能力积累经验。

**风格要求（重要）**：本段只聚焦"个人本周指标达成情况"，不要混入门店客流描述、竞品动态、展会/培训经过等——那些内容应归到对应的"收获/思考/竞品分析"环节。保持精炼，不冗余。例：若本周参加展会未在门店销售，写明"本周工作节奏特殊，X至X参加XX，仅X在门店接待"即可，不要在业绩分析里展开展会细节。

### 个人收获（B11）
分 1-2 点，每点"核心观点 + 场景支撑 + 洞察"。例：
- "销售的核心不是介绍产品，而是找到用户真正关心的问题"——不同用户打动点不同（价格/拍照/系统/续航/成本），先挖掘换机原因再用产品解决。
- "体验带来的说服力往往比参数更有效"——用户来店前已做功课，让其亲身体验比讲参数更易建立信任。

**风格要求（重要）**：
- **承认客观限制，务实不假设**。若某场景无法直接成交（如展会无售卖环节、客流低位），如实说明客观条件限制，再思考在该限制下能做什么（至少沉淀私域/加企微），不要假设"应该提前备好样机当场卖"这种脱离实际的方案。
- **可加竞品对标观察**。如发现友商某做法更好（如"华为展会可直接购买且有折扣"），作为收获写出来，比空谈更有说服力。
- 不用"金矿""当场收网""趁热打铁"等过度修辞，语言自然务实。

### 不足反思与提升计划（B12）
分 1-2 点，每点"现状不足 + 提升计划"。例：
- 产品知识在积累但讲解未成体系 → 针对不同用户类型（苹果换机/性能用户/家庭用户）形成差异化讲解逻辑。
- 门店运营流程理解不深（POS、补贴、调货、库存、前置仓）→ 向同事学习夯实销售链路。

**风格要求（重要）**：
- **目标分层务实**。无法直接成交的场景，先写"沉淀私域"再写"甚至成交"，分层次递进，不要一步到位喊"必须成交"。
- **不写口号化、说教式句子**。如"讲解和体验只是手段，成交才是目的"这类口号删掉，改为具体可做的动作。

### 门店提升机会与提升方案（B14）
200-300 字。从 2-3 个角度提出机会与方案：
- 客户沉淀：进店体验但缺购买动机的用户，需建立企微联系理由（换机咨询/活动通知/新品体验/售后）。
- 线上引流：工作日客流有限，用小红书/抖音做 AI 功能、影像玩法、摄影技巧等内容引流。
- 轻量化活动：音乐、摄影体验、AI 玩法增加驻留时间，让门店成为体验空间。

**风格要求（重要）**：
- **不与其他环节重复**。本段聚焦"门店层面的提升机会与方案"，不要把"收获"里已写过的个人感悟（如展会经历）再展开一遍。每个环节各有主题，思考环节写门店视角，不写个人视角。

### 竞品分析与对标（B16）
长文本，分点叙述。从店长交流或数据系统获取竞品信息后，按以下维度分析（有数据的维度才写）：

1. **销量基线**：本周竞品周销量（vivo/荣耀/小米等），本店 OPPO 周销，标注领先/落后位置。只用一周数据，不做多周区间或月销换算。
2. **产品结构对比（中低端/高端/IOT）**：各品牌高端机占比、中端机占比、IOT 收入对比，找出结构性优势/短板。若有 PC/笔电品类差异，点明。
3. **赢在哪里**：逐条列出本店相对竞品的优势点（总量领先/IOT碾压/Reno压制竞品S系列等），有店长原话优先引用。
4. **输在哪里**：逐条列出短板（高端占比偏低/缺PC品类/品牌总销量落后等），有店长原话优先引用。
5. **新品带来的影响**：竞品本周新机发布对门店客流的双刃剑效应——正面（教育市场、拉动本品咨询）+ 负面（虹吸客流）+ 应对（准备本品对比话术）。
6. **物料与陈列启示**：从竞品物料/陈列做法中可借鉴的点，点到为止，不过度展开"应该怎么做"。

**风格要求**：竞品数据须基于店长交流或数据系统等真实来源，不可臆测；表述简洁，不堆砌建议。

### 下周计划（A19:D21）
固定 3 行，每行一个维度。参考维度示例：销售转化/客户运营/私域经营/门店曝光。每行：
- 序号（1/2/3）
- 参考维度（短词）
- 目标/计划（一句话目标，尽量可量化，如"新增企业微信10个以上"）
- 关键行动计划（具体动作，如"给企业微信的客户发信息告知x10系列可到店感受外观质感，促成预定转化"）

**风格要求（重要）**：
- **具体可执行，不写假设性计划**。不要写"如遇类似高端场合，当场推进成交"这种不确定是否会发生的计划；要写明确能做的动作（给企微客户发什么信息、打磨什么话术、抓哪波客流）。
- 目标在下周基础上小幅提升。

## 四、xlsx 布局与样式规格

输出 Excel 时严格遵循以下规格，以匹配既有模板观感：

| 区域 | 背景色 | 字号 | 字重 | 对齐 | 自动换行 |
|---|---|---|---|---|---|
| A1 标题 | #00925F（OPPO绿） | 14pt | bold | center/center | 否 |
| A2~A4 标签 / B2~B4 值 | 无 | 11pt | 值bold | center/center | 否 |
| A5/A10/A13/A17 一级标题 | 无 | 11pt | bold | center/center | 否 |
| A6/A15 二级标题 | #FFFFFF | 11pt | normal | left/center | 是 |
| A7:J7 指标表头 | #D9D9D9（浅灰） | 11pt | normal | center/center | 否 |
| A8:J8 指标值 | 无 | 11pt | normal | center/center | 否 |
| B9/B11/B12/B14/B16 长文本 | 无 | 11pt | normal | center/center | 是 |
| A18:D18 计划表头 | 无 | 11pt | normal | center/center | 否 |
| A19:D21 计划数据 | 无 | 11pt | normal | center/center | 是 |

- 字体：全表微软雅黑（macOS 无该字体时用等宽中文替代）。
- 合并：A1:J1、A5:J5、A6:J6、A9:J9（B9内容）、A10:J10、B11:J11、B12:J12、A13:J13、B14:J14、A15:J15、B16:J16、A17:J17、A18:D18 不合并（表头四列），A19:D21 各单元格独立。
- 列宽参考（px）：A155 B110 C87 D86 E110 F82 G91 H85 I97 J108。
- 长文本行行高显著放大（约 150-240px），长文本单元格内用 \n 段落分隔。

## 五、周报自动汇总流程（核心）

用户下"写周报"指令时，**自动汇总本周日报**生成周报，流程如下：

### 第 1 步：聚合本周日报
运行聚合脚本，扫描本周（周一~周六）的存档日报：

```bash
python3 scripts/aggregate_weekly.py [--week-date YYYY-MM-DD]
```

脚本输出 JSON，包含：
- `week_mon`/`week_sat`：本周周一、周六日期
- `totals`：周一~周六日报 10 项 KPI 累计值（phone/iot/paid_film/trade_in/ent_wechat/dianping/map_review/free_film/douyin/xiaohongshu）
- `reports`：各日日报路径及 metrics、是否有典型案例/收获思考
- `missing_days`：缺失日报的日期列表

### 第 2 步：处理缺失日报与周日数据
- 若 `missing_days` 非空（有未写日报的工作日），询问用户这些日期的数据，或由用户确认跳过/补录。
- 周日（无日报）的数据由用户补充：当日新增的销量、企微、贴膜等，累加进周累计。
- 将脚本 `totals` + 周日用户补充数据 = 周报 10 项指标最终值。

### 第 3 步：读取各日典型案例与收获
逐份读取本周存档日报的【典型案例】【收获与思考】文本，提炼本周亮点：
- 业绩分析：结合 10 项累计值 + 成交机型覆盖系列，按规范字数撰写。
- 个人收获：从本周各日典型案例提炼 1-2 点核心洞察。
- 不足反思：从各日反思中提炼共性不足与提升计划。
- 门店思考：综合本周观察提出 2-3 个提升机会与方案。

### 第 4 步：补全头部与下周计划
- 标题"上海团队 {姓名} 第 {N} 周总结"、派驻地/售点/姓名（固定字段记忆复用）。
- 下周计划 3 行（销售能力提升/客户运营/门店曝光等维度），在下周目标基础上小幅提升。

### 第 5 步：输出
按用户指定形态输出：纯文本预览 或 .xlsx（严格按第四节样式规格生成）。

## 六、写周报所需信息清单（当日报不全时）

当本周日报存档不完整、无法自动汇总时，向用户索取以下信息：
1. 姓名/周数/派驻地/售点（固定字段记忆复用）。
2. 本周 10 项指标累计值（手机独销/IOT独销/付费膜/当换/有效企微/大众点评/地图好评/免费贴膜/抖音/小红书）。
3. 本周成交机型覆盖系列（Find/Reno/一加/A）。
4. 本周典型案例与收获要点（给要点由 AI 扩写）。
5. 不足反思与门店提升思考要点。
6. 下周计划 3 行。
7. 输出形态：纯文本 或 .xlsx。

## 七、语言风格自检清单（成文前必查）

以下规则提炼自用户对周报的亲自修改，是判断"是否像导购本人写的"的核心标准：

1. **不跨环节重复**：同一内容只出现在一个环节。如展会收获写在"个人收获"里，"个人思考"就不再重复展开。每个环节各有主题：业绩分析写指标达成、收获写个人感悟、思考写门店视角、竞品分析写对标。
2. **承认客观限制，务实不假设**：若某场景无法直接成交（如展会无售卖环节），如实写明限制，再思考在该限制下能做什么（至少沉淀私域）。不要写"应该提前备好样机当场卖"这种脱离实际的方案。
3. **目标分层递进**：无法直接成交 → 先写"沉淀私域"再写"甚至成交"，分层次递进，不要一步到位喊"必须成交"。
4. **不写口号化/说教式句子**：如"讲解和体验只是手段，成交才是目的""缩短链路、当场收网"这类口号删掉，改为具体可做的动作。
5. **业绩达成分析聚焦个人指标**：只写个人本周指标达成情况，不混入门店客流描述、竞品动态、展会/培训经过等。
6. **下周计划具体可执行**：不写"如遇类似高端场合"这种假设性计划，要写明确能做的动作（给企微客户发什么信息、打磨什么话术、抓哪波客流）。
7. **不用过度修辞**：避免"金矿""趁热打铁""当场收网"等夸张表达，语言自然务实。
8. **竞品数据有出处**：竞品销量/占比须基于店长交流或数据系统等真实来源，不可臆测；只用一周数据，不做多周区间或月销换算。
